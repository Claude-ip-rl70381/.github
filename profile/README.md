<p>第一项，地址独占验证。问清分配方式，看这段地址是否只分配给你。这一项靠沟通确认，辅以查询段的使用情况。</p>

<p>第二项，带宽独占验证。在空闲时段和高峰时段各测一轮，比较延迟与吞吐的变化幅度。变化明显说明带宽是共享的，与宣称不符。</p>

<p>第三项，会话独占验证。同时开多个会话，看成功率与延迟怎么变，以及有没有并发上限被触发的迹象。超并发后是排队还是拒绝，也要记下来。</p>

<p>一项观察，是可用性随时间的走势。连续观察几天，看成功率是否有规律性下滑，故障恢复用了多久。独享方案没有邻居缓冲，走势比单点数据更有意义。</p>

<p>四项做完，结论通常很明确：这条是真的独享，还是只是地址独享。两种都能用，但价格应该不同。</p>

<p>评测时要注意控制变量。换时段测的时候，请求内容、并发、间隔都要保持一致，否则数据不可比。</p>

<p>关于高峰期的判断，建议用同一地区的另一条线路做对照。没有对照，很难区分是线路拥塞还是本地网络问题。</p>
